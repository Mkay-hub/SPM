# SPM
This is a android smart pantry management system for leftover food items.

## Database Choice: 
Firestore is my choice for a database for this mobile application. As it requires no schema, nor SQL syntax. 
It stores all the recipe ingrident's as an array in one documment, and caches any new recorded data offline. 
Offline caching comes as a default option provided by the Andriod SDK.
